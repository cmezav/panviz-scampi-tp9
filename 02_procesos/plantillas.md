# Plantillas de control reutilizables

**Requisito.** ID R, flujo, necesidad, criterio medible, fuente, versión, responsable, prueba de aceptación, estado.

**Revisión.** ID, impacto, artefacto y versión, autor real, revisor distinto, comprobación, observación, decisión, fecha, discrepancia y siguiente acción.

**Prueba.** ID T, R, característica, versión, datos y entorno, precondiciones, pasos, esperado, observado, duración, resultado, evidencia, ejecutor real.
